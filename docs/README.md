## 快速查阅

### 实测性能速查

| 指标 | 数值 |
|------|------|
| Accuracy | 87.32% |
| Macro F1 | 0.8197 |
| avg F1（失衡 + 摔倒） | 0.7745 |
| 摔倒类召回 | 98.59%（4054 窗口中仅漏检 5 个） |
| 单帧推理耗时 | ~30 ms（检测 20.2 ms + 姿态 11.3 ms） |

### 预警等级速查

| 等级 | 触发条件 |
|------|----------|
| `SAFE` | 默认状态 |
| `LOW_RISK` | P₁ > 0.60 连续 3 次 |
| `HIGH_RISK` | P₁ > 0.75 连续 2 次 |
| `IMMEDIATE` | P₂ > 0.85 连续 5 次 |

### 关键参数速查

| 参数 | 值 | 说明 |
|------|-----|------|
| 帧率 | 15 fps | 训练与推理必须一致 |
| 滑窗 | 30 帧 | ≈ 2 秒上下文 |
| 特征通道 | 9 | 增强特征 |
| 分类数 | 3 | 正常 / 失衡 / 摔倒 |
| 数据划分 | 按视频 8:2，`RandomState(42)` | 防泄漏、可复现 |
