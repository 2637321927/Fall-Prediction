# annotations/ — 标注源文件与规范

本目录存放**人工标注的源文件**，是生成帧级标签（`data/labels/*.npy`）的输入。

---

## 一、文件清单

| 文件 | 覆盖视频 | 说明 |
|------|----------|------|
| `标注.xlsx` | `h*` 系列 | 与 `h标注.xlsx` 内容重复 |
| `h标注.xlsx` | `h*` 系列 | h 系列视频的阶段标注 |
| `标注o.xlsx` | `o*` 系列 | o 系列视频的阶段标注 |
| `L标注2.xlsx` | `L*` 系列 | L 系列视频的阶段标注 |
| `标注说明.txt` | — | 标注任务书：数据集取舍、标注字段定义、数据组交付要求 |

> `c*` 系列视频的标注同样记录在 `标注.xlsx` 中（该文件为多系列合并版本）。

## 二、标注格式

每个 sheet 一行对应一个视频：

```text
视频名 | 起始帧 | 状态 | 起始帧 | 状态 | 起始帧 | 状态 | ...
```

- **起始帧**：1-based，表示该状态从这一帧开始
- **状态**：`0 = 正常`、`1 = 不分正常`（失衡/可疑）、`2 = 摔倒`
- 最后一个状态持续到视频结束
- 正常视频只需一行 `视频名 | 1 | 0`

示例：

```text
h1   1  0   145  1   168  2       # 0~144 帧正常 → 145~167 帧失衡 → 168 帧起摔倒
o1   1  0   288  1   304  2       # 0~287 帧正常 → 288~303 帧失衡 → 304 帧起摔倒
L15  1  0                          # 全程正常
```

## 三、转换为帧级标签

```bash
cd src

# 先预览（不写盘）
python make_labels_from_xlsx.py --dry_run

# 确认无误后正式生成到 data/labels/
python make_labels_from_xlsx.py
```

脚本会：
1. 读取本目录下的 4 个 xlsx 文件
2. 按视频名匹配 `data/keypoints/<name>_keypoints.npy`（大小写不敏感）
3. 生成与之等长的 `data/labels/<name>_labels.npy`
4. **检测冲突**：同一视频在多个 xlsx 中标注不一致时打印警告

### 常见冲突

`标注.xlsx` 与 `h标注.xlsx` 都包含 `h*` 系列，若两份内容不同会报冲突。
当前两份内容一致，重复读取不会改变结果（幂等）。

## 四、标注规范（4 个关键时间点）

跌倒视频需要标注 **4 个关键时间点**，定义如下：

| 字段 | 含义 |
|------|------|
| `risk_start_frame` | 开始出现明显失衡风险（身体异常前倾/后倾/侧倾、脚步补偿失败、重心明显偏移） |
| `fall_start_frame` | 已经开始不可恢复地下坠，身体明显进入跌倒过程 |
| `impact_frame` | 身体首次接触地面 / 床 / 椅子等承托物 |
| `stable_fallen_frame` | 倒地后姿态基本稳定，不再明显移动 |

正常视频不填这四个字段，全部留空。

> 📌 **标注以原始视频为准，不以 YOLO / 骨架提取结果为准。**
> 标注组无需运行姿态提取，只需交付视频清单与事件时间点。

完整的数据集取舍与数据组任务要求见 [`标注说明.txt`](标注说明.txt)。

## 五、交互式标注（补充手段）

若需要逐帧精修，可用可视化工具：

```bash
cd src
python label_video.py --video ../video/CGFM1.mp4
```

| 按键 | 功能 |
|------|------|
| `空格` | 播放 / 暂停 |
| `←` `→` | 逐帧后退 / 前进 |
| `+` | 新增事件 |
| `D` | 删除事件 |
| `R` / `F` / `I` / `S` | 标记 risk_start / fall_start / impact / stable_fallen |
| `N` | 清空（标记为正常视频） |
| `Q` | 保存并退出 |

输出：`data/labels/<name>_labels.npy` + `<name>_info.json`（标注详情）
